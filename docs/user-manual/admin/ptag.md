![P-tag layout](figures/admin-ptag.png)

**P-tag** designs the compatibility tag issued with a unit and the fold-under form used to verify it. One layout is active. Issue and Printing both use that layout.

Include the patient identifiers, the unit identifiers, and the crossmatch information your procedure requires the ward to see. If facility policy requires a scanned P-tag id before issue, the printed tag must carry that id as a barcode the issue form can read. A tag that looks right but will not scan stops issue at the desk.

Activate a changed layout only after a test print. Tags already printed keep the layout they were printed with. They are not reprinted automatically.
