![Coded comments](figures/admin-coded-comments.png)

**Coded Comments** are the shortcuts that appear in comment fields. Each row has a code, the text it inserts, and the pages it belongs on: Patient, Order, Specimen, or Tests. A code defined for specimens does not appear on the patient comment.

Write the text as a complete comment. The bench inserts it and can add to it. Changing the text changes what the shortcut inserts next time. It does not rewrite comments already saved on charts.

Retire a code that your procedure no longer wants by inactivating it. Reusing the same code for a different sentence later will confuse anyone who learned the old expansion.
