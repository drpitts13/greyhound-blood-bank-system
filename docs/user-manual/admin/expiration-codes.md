![Expiration codes](figures/admin-expiration-codes.png)

**Expiration Codes** are the ISBT expiration-modification codes applied when processing changes the dating, for example after irradiation or pooling. The modification rule points at a code. The code calculates the new expiration. The bench does not type a new date.

A wrong code leaves thawed or irradiated units with the original expiration, or shortens dating that should have been unchanged. Compare the calculated date on a training unit with your procedure before you activate the rule that uses the code.

These codes are part of the same licensing caution as the product-code catalog. Enter a code your license covers. Do not copy a table from an unlicensed source into this screen.
