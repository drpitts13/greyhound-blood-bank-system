**Discard Reasons** is the list the unit page requires when a unit is discarded. A unit cannot be discarded without an active code. The code is stored on the unit, and the **Wastage by product and reason** report counts discards by month, product, and code.

The starter list is an example for your facility to edit: expired, bag damage, failed visual inspection, temperature out of range, returned and not eligible for reissue, recall, and Other. It is not a regulatory list.

Tick **Comment required** for a catch-all code such as Other, so the person discarding must explain. Other codes accept an optional comment. The unit stores the reason text, followed by the comment when there is one.

Deactivate a code to stop new discards from using it. Units already discarded keep the code they were given.
