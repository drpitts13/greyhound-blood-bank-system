**Specimen Rejection Reasons** is the list the chart and the test worklist require when a specimen is rejected. A specimen cannot be rejected without an active code. The code is stored on the specimen with the reason text, so rejections can be counted by cause, for example by ward or collector.

The starter list is an example for your facility to edit: hemolyzed, clotted, quantity not sufficient, unlabeled, label incomplete or not matching the requisition, suspected wrong blood in tube, wrong tube type, too old to test, and Other. It is not a regulatory list.

Tick **Comment required** for a code that needs an explanation. The starter list requires one for suspected wrong blood in tube and for Other. Other codes accept an optional comment. The specimen stores the reason text, followed by the comment when there is one.

Deactivate a code to stop new rejections from using it. Specimens already rejected keep the code they were given. Changes are kept in configuration history.
