**Order Cancellation Reasons** is the list the order screen requires. Cancellation cannot be saved without a code. Add a reason for each situation your procedure distinguishes, such as duplicate order, patient discharged, or collected on the wrong patient. The code and the explanation are both stored on the order.

Do not add a single reason called "Other" and expect the bench to explain in a comment if your procedure needs the reason to be reportable. The code is what reports and the audit trail group on.

Inactivate a reason to stop new cancellations from using it. Orders already cancelled keep the reason they were given.
