## The page is not in the sidebar

The sidebar hides screens your session cannot open. Check **Your access** on the dashboard. If the permission is missing, an administrator has to grant the role. Signing in again is required after a role change.

A web address that does not match a screen shows **not found**. Use the sidebar or Help rather than editing the address. The not-found page is not a clinical record.

## The action is blocked

Read the alert. A hard stop names the rule that failed. Fix that condition. A warning names the override. If you do not have the override permission, the warning is as far as you can go. Find a supervisor rather than trying the action on a different screen. The Products tab, Compatibility, and Issue and Transfuse all run the same gate.

If Help for this page opens [Safety checks](safety), you are on a screen whose block is one of the issue or crossmatch rules.

## The application shows an error

An unhandled error offers **Reload**. Reload once. If the error returns, note the screen you were on and the time, and tell the person who supports the system. Do not re-enter the same save repeatedly. You may create a duplicate order, result, or issue if the first save succeeded and only the confirmation failed.

If you were signed out, the session expired or was revoked. Sign in again. Unsaved fields on the form are not kept.

## Figures in this guide

Screenshots in the PDF and in Help are from the training database. Your facility's catalog names, printers, and policies will differ. The steps are the same. The labels on a few administrator screens follow your configuration.
